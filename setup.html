1 · Let the phone install it

Android blocks installs from outside a store until you allow it, once, for whichever app is doing the installing. When the browser asks, allow it — or find it under Settings → Apps → Special access → Install unknown apps.

Prefer a cable? adb install -r BrightMarket.apk

2 · Open it and pick how you want to use it

First launch asks one question, because the answer changes what the app is:

  • Browse here — search and discover on the phone, like any store.
  • Focus mode — no browsing on the phone at all. You browse the catalogue on a computer and send apps over by QR. Everything you have installed still updates.

Focus mode can be turned on later in Settings. Turning it back off is only possible by scanning a code from the catalogue page — which is the point of it. It is a commitment device, not a lock: that code is an ordinary link and anyone determined can make one.

3 · Install an app

Pick anything in the catalogue and scan its code, or browse on the phone if you left focus mode off. Nothing installs until you tap Install there.

4 · Apps that are not in the catalogue

Scan any GitHub repo URL that publishes APK releases and BrightMarket tracks it for updates alongside everything else. Those are marked UNLISTED, because their downloads cannot be checked against a published hash the way indexed apps are.

5 · Coming from Obtainium

Export from Obtainium, then Settings → Import from Obtainium. Apps in the catalogue become normal entries and the rest are tracked as unlisted. Anything without a GitHub repo behind it is reported rather than dropped, since there is nothing to check for updates against.

Keeping up to date

The Updates tab compares what is installed against the newest release and offers Update All. BrightMarket updates itself the same way, and always last in a batch — installing it closes the app, so anything queued behind it would never run.
