Set up BrightMarket

A catalogue of apps built for the Light Phone III, and a way to install them that does not put a store on the phone. It takes about two minutes.

On the phone. Open this page in the Light Phone's browser and tap the button. The file lands in Downloads and the browser offers to install it. Short link, if you are typing it in: brightmarket.gzl.dev/setup

DOWNLOAD THE APK SEE THE APPS FIRST

From a computer. Download the same file, plug the phone in, and push it across:

adb install -r BrightMarket.apk

Needs USB debugging on the phone — step 1 below has the walk.

1 · Get it onto the phone

Two ways, and they end in the same place. Pick whichever is in front of you.

In the phone's browser

Open brightmarket.gzl.dev/setup on the Light Phone and tap Download the APK. When the download finishes, open it from the notification or from Downloads.

Android refuses installs from outside a store until you allow it, once, for whichever app is doing the installing — here that is the browser. It asks the first time; say yes. If you dismissed the prompt, it is under Settings → Apps → Special access → Install unknown apps, then pick the browser and turn it on.

Over a cable

Download the APK on a computer that has adb, then turn on USB debugging: Settings → About phone, tap Build number seven times, then Settings → System → Developer options → USB debugging.

Plug the phone in. It asks whether to trust the computer — say yes, or nothing below will see it.

adb devices — the phone should be listed as device. unauthorized means the trust prompt is still waiting on the screen.

adb install -r BrightMarket.apk

-r replaces an existing copy instead of failing. If it reports INSTALL_FAILED_UPDATE_INCOMPATIBLE, a build signed by a different key is already installed — uninstall that first, and it takes its settings with it.

2 · Open it and pick how you want to use it

First launch asks one question, because the answer changes what the app is:

  • Browse here — search and discover on the phone, like any store.
  • Focus mode — no browsing on the phone at all. You browse the catalogue on a computer and send apps over by QR. Everything you have installed still updates.

Focus mode can be turned on later in Settings. Turning it back off is only possible by scanning a code from the catalogue page — which is the point of it. It is a commitment device, not a lock: that code is an ordinary link and anyone determined can make one.

3 · Install an app

Pick anything in the catalogue and scan its code, or browse on the phone if you left focus mode off. Nothing installs until you tap Install there.

4 · Apps that are not in the catalogue

Scan any GitHub repo URL that publishes APK releases and BrightMarket tracks it for updates alongside everything else. Those are marked UNLISTED, because their downloads cannot be checked against a published hash the way indexed apps are.

5 · Coming from Obtainium

Export from Obtainium, then Settings → Import from Obtainium. Apps in the catalogue become normal entries and the rest are tracked as unlisted. Anything without a GitHub repo behind it is reported rather than dropped, since there is nothing to check for updates against.

Keeping up to date

The Updates tab compares what is installed against the newest release and offers Update All. BrightMarket updates itself the same way, and always last in a batch — installing it closes the app, so anything queued behind it would never run.
